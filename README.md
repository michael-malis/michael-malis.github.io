# Michael Malis — Portfolio

Personal portfolio site for Michael Malis, Statistics & Data Science student at the Hebrew University of Jerusalem.

**Live:** https://michael-malis.github.io/

## Tech Stack

- React 18 + Vite 8
- Tailwind CSS v4
- Three.js / React Three Fiber (lazy-loaded)

## Development

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview production build
```

## Structure

```
src/
  components/   React components (one per section)
  data/         Static data (projects, skills, awards)
  assets/       Images and static assets
  hooks/        Custom React hooks
public/         Static files served as-is
```
